# FS-ASM

FS-ASM to rozwijany runtime agentowy: trwały stan i program zadań poza pamięcią LLM, kontrola wykonania przez kod oraz niezależne dowody ukończenia. Repozytorium jest środowiskiem budowy; działający runtime docelowo zostanie uruchomiony na komputerze użytkownika.

**Linia dalszego rozwoju:** `Fsasm-experimental`. `main` jest odrębną, starszą linią; nie synchronizuj jej automatycznie.
